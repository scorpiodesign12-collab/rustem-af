§ 7. Линейные операции над векторами

7.1 Выразить AM через AB и AC (M — середина BC).
AM = AB + BM = AB + ½BC = AB + ½(AC − AB) = ½(AB + AC).Ответ: AM = ½(AB + AC)
7.2 В параллелограмме ABCD: AC = p, BD = q. Выразить AB и AD.
AC = AB + AD = p, BD = AD − AB = q. Складываем: 2AD = p + q; вычитаем: 2AB = p − q.Ответ: AB = ½(p − q), AD = ½(p + q)
7.3 Доказать: AA₁ + BB₁ + CC₁ = 0 (медианы).
AA₁ = ½(AB + AC), BB₁ = ½(BA + BC), CC₁ = ½(CA + CB). Сумма = ½[(AB + BA) + (AC + CA) + (BC + CB)] = 0, так как каждая пара противоположных векторов даёт 0.Ответ: Сумма равна 0 ∎
7.4 a = (2; −1; 3), b = (−1; 4; 0). Найти 3a − 2b и его длину.
3a = (6; −3; 9), 2b = (−2; 8; 0). 3a − 2b = (8; −11; 9). Длина: √(64 + 121 + 81) = √(266).Ответ: 3a − 2b = (8; −11; 9), длина √(266)
7.5 При каком m векторы a = (m; 3; −2) и b = (4; −6; 4) коллинеарны? Направление?
Пропорциональность: m/4 = 3/(−6) = −2/4. Отсюда коэффициент −½ и m = 4·(−½) = −2. Коэффициент отрицателен, значит, векторы направлены противоположно.Ответ: m = −2, противоположно направлены
7.6 a = (3; −4; 12): длина, орт, направляющие косинусы.
|a| = √(9 + 16 + 144) = 13. Орт a⁰ = a/|a|. Его координаты — направляющие косинусы.Ответ: |a| = 13, a⁰ = (3/13; −4/13; 12/13), cos α = 3/13, cos β = −4/13, cos γ = 12/13
7.7 Разложить d = (1; 4; 7) по e₁ = (1; 1; 0), e₂ = (0; 1; 1), e₃ = (1; 0; 1).
d = x·e₁ + y·e₂ + z·e₃: x + z = 1, x + y = 4, y + z = 7. Сложив, 2(x + y + z) = 12, x + y + z = 6. Тогда z = 6 − 4 = 2, x = 6 − 7 = −1, y = 6 − 1 = 5.Ответ: d = −e₁ + 5e₂ + 2e₃
7.8 Показать, что a = (1; 2; 3), b = (2; −1; 1), c = (4; 3; 7) линейно зависимы.
Ищем c = λa + μb: λ + 2μ = 4, 2λ − μ = 3. Из первого λ = 4 − 2μ, подставляем: 8 − 5μ = 3, μ = 1, λ = 2. Проверка третьей координаты: 3·2 + 1 = 7 ✓. Значит, c выражается через a и b — векторы зависимы.Ответ: c = 2a + b
7.9 Лежат ли A(1; −2; 0), B(3; 0; −3), C(5; 2; −6) на одной прямой?
AB = (2; 2; −3), AC = (4; 4; −6) = 2·AB. Векторы коллинеарны и имеют общую точку A.Ответ: Да, AC = 2AB
7.10 Решить 2x − 3a = 5b + x.
Переносим x влево: 2x − x = 3a + 5b.Ответ: x = 3a + 5b
7.11 Центр тяжести треугольника A(1; 2; 3), B(−1; 0; 5), C(3; 4; 4).
Центр тяжести — среднее арифметическое вершин: x = (1 − 1 + 3)/3 = 1, y = (2 + 0 + 4)/3 = 2, z = (3 + 5 + 4)/3 = 4.Ответ: M(1; 2; 4)
7.12 Сумма векторов из центра правильного n-угольника в вершины равна 0.
Пусть s — эта сумма. Поворот на угол 2π/n вокруг центра переводит многоугольник в себя, а вершины переставляет, поэтому s не меняется. Но поворот на ненулевой угол меняет любой ненулевой вектор. Значит, s = 0.Ответ: s = 0 ∎
7.13 Отрезки, соединяющие середины противоположных рёбер тетраэдра, пересекаются в одной точке и делятся ею пополам.
Середины AB и CD: ½(rA + rB) и ½(rC + rD). Середина отрезка между ними: ¼(rA + rB + rC + rD). Выражение симметрично по вершинам, поэтому для двух других пар противоположных рёбер получается та же точка.Ответ: Все три отрезка пересекаются в точке ¼(rA + rB + rC + rD) и делятся ею пополам ∎
7.14 При каких α, β: αa + βb = 0 для неколлинеарных a, b? Что для коллинеарных?
Если α ≠ 0, то a = −(β/α)·b — коллинеарны, противоречие. Значит, α = 0, тогда βb = 0 и β = 0. Для коллинеарных b = ka: αa + βka = (α + βk)a = 0 при α = −βk — бесконечно много ненулевых решений.Ответ: Только α = β = 0; для коллинеарных есть и ненулевые α, β

§ 8. Скалярное произведение

8.1 a = (4; −2; −4), b = (6; −3; 2): (a, b), |a|, |b|, cos φ, пр_a b.

8.2 При каком λ a = (λ; 2; −1) ⊥ b = (3; −1; λ)?

8.3 |a| = 2, |b| = 3, угол 120°. Найти |a + b|, |a − b|.
(a, b) = 2·3·cos 120° = −3. |a + b|² = 4 + 9 + 2·(−3) = 7. |a − b|² = 4 + 9 − 2·(−3) = 19.Ответ: |a + b| = √(7), |a − b| = √(19)

(a + b, a − b) = |a|² − |b|² = 4 − 9 = −5. cos ψ = −5/(√(7)·√(19)) = −5/√(133) ≈ −0,4336.Ответ: cos ψ = −5/√(133), ψ ≈ 115°42′
8.5 e₁, e₂, e₃ единичные, углы по 60°. Найти |e₁ + e₂ + e₃|.
(eᵢ, eⱼ) = cos 60° = ½. |e₁ + e₂ + e₃|² = 3·1 + 2·3·½ = 6.Ответ: √(6)
8.6 |a| = 3, |b| = 5. При каком α (a + αb) ⊥ (a − αb)?
(a + αb, a − αb) = |a|² − α²|b|² = 9 − 25α² = 0.Ответ: α = ±3/5
8.7 Работа силы F = (3; −2; 5) при перемещении из A(2; −3; 1) в B(4; 1; −2).
s = AB = (2; 4; −3). A = (F, s) = 6 − 8 − 15 = −17.Ответ: A = −17
8.8 x ∥ a = (2; 1; −1), (x, b) = 6, b = (3; −1; 2).
x = t·(2; 1; −1). (x, b) = t(6 − 1 − 2) = 3t = 6, t = 2.Ответ: x = (4; 2; −2)
8.9 Углы треугольника A(−1; −2; 4), B(−4; −2; 0), C(3; −2; 1).
AB = (−3; 0; −4), AC = (4; 0; −3). (AB, AC) = −12 + 12 = 0, значит ∠A = 90°. |AB| = |AC| = 5, поэтому ∠B = ∠C = 45°.Ответ: ∠A = 90°, ∠B = ∠C = 45°; прямоугольный равнобедренный
8.10 Разложить b = (3; −1; 2) на составляющие ∥ и ⊥ a = (1; 1; 0).
(b, a) = 3 − 1 = 2, (a, a) = 2. b∥ = (2/2)·a = (1; 1; 0). b⊥ = b − b∥ = (2; −2; 2). Проверка: (b⊥, a) = 2 − 2 = 0 ✓.Ответ: b∥ = (1; 1; 0), b⊥ = (2; −2; 2)
8.11 Направляющие косинусы a = (2; −1; 2), проверить тождество.
|a| = √(4 + 1 + 4) = 3. cos α = 2/3, cos β = −1/3, cos γ = 2/3. Сумма квадратов: 4/9 + 1/9 + 4/9 = 1 ✓.Ответ: cos α = 2/3, cos β = −1/3, cos γ = 2/3
8.12 Углы a = (1; 1; √2) с осями.
|a| = √(1 + 1 + 2) = 2. cos α = ½, cos β = ½, cos γ = √2/2.Ответ: 60°, 60°, 45°
8.13 Тождество параллелограмма.
|a + b|² = |a|² + 2(a, b) + |b|², |a − b|² = |a|² − 2(a, b) + |b|². Складываем: удвоенные произведения сокращаются, получаем 2(|a|² + |b|²).Ответ: Сумма квадратов диагоналей параллелограмма равна сумме квадратов всех его сторон ∎
8.14 |a + b| = |a − b| ⇔ a ⊥ b.
Возведём в квадрат: |a|² + 2(a, b) + |b|² = |a|² − 2(a, b) + |b|², то есть 4(a, b) = 0, а это равносильно a ⊥ b.Ответ: Параллелограмм с равными диагоналями — прямоугольник ∎
8.15 Вывести теорему косинусов.
BC = AC − AB. |BC|² = (AC − AB, AC − AB) = |AC|² − 2(AB, AC) + |AB|², а (AB, AC) = |AB||AC|cos A.Ответ: |BC|² = |AB|² + |AC|² − 2|AB||AC|cos A ∎
8.16 Неравенство Коши — Буняковского.
(a, b) = |a||b|cos φ и |cos φ| ≤ 1, поэтому |(a, b)| ≤ |a||b|. Равенство при |cos φ| = 1, то есть φ = 0° или 180°.Ответ: Равенство достигается для коллинеарных векторов ∎
