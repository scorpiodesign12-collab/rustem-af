Задание 1

Точка M₀ и прямая ℓ

M₀(3+λ+ν; 3+μ−ν) = M₀(6; 3). Прямая ℓ: (λ+1)x+(μ+1)y = 2−λ²−μ²+(λ−μ)ν → 2x + 3y + 5 = 0
а) Расстояние d от M₀ до ℓ

Для прямой Ax+By+C=0 и точки (x₀,y₀):

d = |A·x₀ + B·y₀ + C| / √(A²+B²)

d = |2·6 + 3·3 + 5| / √(2²+3²) = |12+9+5| / √13 = 26/√13 = 2√13

Ответ: d = 2√13 ≈ 7,21
б) Прямая ℓ₁ через M₀ перпендикулярно ℓ

Нормаль ℓ: n = (2, 3). Прямая ℓ₁ ⟂ ℓ ⇒ её нормаль перпендикулярна n, т.е. n₁ = (3, −2) (координаты поменяли местами и один знак сменили).

ℓ₁: 3(x−6) − 2(y−3) = 0

3x − 18 − 2y + 6 = 0

Ответ: ℓ₁: 3x − 2y − 12 = 0
в) Проекция P точки M₀ на ℓ

P — точка пересечения ℓ и ℓ₁:

2x + 3y = −5,   3x − 2y = 12

Умножаем первое на 2, второе на 3 и складываем: 4x+6y=−10; 9x−6y=36 ⇒ 13x=26 ⇒ x=2. Из первого уравнения: 2·2+3y=−5 ⇒ y=−3.

Ответ: P(2; −3)

Проверка: |M₀P| = √((6−2)²+(3+3)²) = √(16+36) = √52 = 2√13 — совпадает с d из пункта а).

г) Проверка на чертеже

На чертеже видно, что отрезок M₀P действительно перпендикулярен прямой ℓ, а точка P лежит на пересечении ℓ и ℓ₁.

ℓ (сплошная), ℓ₁ (пунктир) и отрезок M₀P — видно, что P лежит на пересечении и M₀P ⟂ ℓ
Задание 2

Точки M₁, M₂ и прямая ℓ

M₁(ν−3; λ−3μ+6) = M₁(−1; 1), M₂(ν−1; λ−μ+1) = M₂(1; 0). Прямая ℓ: (2μ−3)x−2y+2λ−5+ν(3−2μ) = 0 → x − 2y − 5 = 0
а) Уравнение прямой M₁M₂

Направляющий вектор: M₁M₂ = (1−(−1); 0−1) = (2; −1).

(x−(−1))/2 = (y−1)/(−1)

−(x+1) = 2(y−1) ⇒ −x−1 = 2y−2 ⇒ x+2y−1 = 0

Ответ: M₁M₂: x + 2y − 1 = 0
б) Угол φ между M₁M₂ и ℓ

Нормали: n₁ = (1, 2) для M₁M₂, n₂ = (1, −2) для ℓ.

cos φ = |n₁·n₂| / (|n₁|·|n₂|)

n₁·n₂ = 1·1 + 2·(−2) = 1−4 = −3. |n₁| = |n₂| = √5.

cos φ = |−3| / (√5·√5) = 3/5

Ответ: φ = arccos(3/5) ≈ 53,13°
в) Точка пересечения Q прямых M₁M₂ и ℓ
x + 2y = 1,   x − 2y = 5

Складываем: 2x = 6 ⇒ x = 3. Из первого: 3+2y=1 ⇒ y=−1.

Ответ: Q(3; −1)
г) Проверка на чертеже

На чертеже прямые M₁M₂ и ℓ действительно пересекаются в точке Q(3;−1).

Прямая M₁M₂ (сплошная) и ℓ (пунктир) пересекаются в Q(3;−1)
Задание 3

Плоскость по трём точкам

M₀(μ+1; 1−λ; ν+1) = M₀(3; 0; 3), M₁(μ; −λ; ν+1) = M₁(2; −1; 3), M₂(2μ; −2λ; ν+2) = M₂(4; −2; 4), M₃(μ+1; 1−λ; ν) = M₃(3; 0; 2)
а) Уравнение плоскости Π через M₁, M₂, M₃

Векторы в плоскости: M₁M₂ = (2; −1; 1), M₁M₃ = (1; 1; −1).

Нормаль n = M₁M₂ × M₁M₃:

n = ( (−1)(−1)−1·1 ; −(2·(−1)−1·1) ; 2·1−(−1)·1 ) = (0; 3; 3) ~ (0; 1; 1)

Плоскость через M₁(2,−1,3) с нормалью (0,1,1): 0(x−2)+1(y+1)+1(z−3)=0

Ответ: Π: y + z − 2 = 0

Проверка: M₂(4,−2,4): −2+4−2=0 ✓; M₃(3,0,2): 0+2−2=0 ✓

б) Расстояние d от M₀ до Π
d = |0·3 + 1·0 + 1·3 − 2| / √(0²+1²+1²) = |1| / √2
Ответ: d = 1/√2 = √2/2 ≈ 0,71
в) Плоскость Π₁ через M₀ параллельно Π

Та же нормаль (0,1,1), проходит через M₀(3,0,3):

0(x−3) + 1(y−0) + 1(z−3) = 0
Ответ: Π₁: y + z − 3 = 0
Задание 4

Плоскость Π и прямая L

Π: (λ+1)x+(1−μ)y+z=ν(λ+1) → 2x − y + z = 4. L: { λx−μy+z=λν ; x+y+z=μ+λ+ν } → { x−2y+z=2 ; x+y+z=5 }
а) Направляющий вектор прямой L

Нормали плоскостей системы: n₁=(1,−2,1), n₂=(1,1,1). Направляющий вектор s = n₁ × n₂:

s = ( (−2·1−1·1) ; −(1·1−1·1) ; (1·1−(−2)·1) ) = (−3; 0; 3) ~ (−1; 0; 1)
Ответ: s = (−1; 0; 1)
б) Угол θ между L и Π

Нормаль плоскости n_Π = (2,−1,1).

sin θ = |s·n_Π| / (|s|·|n_Π|)

s·n_Π = (−1)·2+0·(−1)+1·1 = −2+0+1 = −1. |s|=√2, |n_Π|=√6.

sin θ = 1/(√2·√6) = 1/√12 = √3/6

Ответ: θ = arcsin(√3/6) ≈ 16,78°
в) Канонические и параметрические уравнения L

Найдём точку на L: пусть z=0 ⇒ x−2y=2, x+y=5. Вычитая: 3y=3 ⇒ y=1, x=4. Точка (4; 1; 0) (проверено в обоих уравнениях).

Каноническая: (x−4)/(−1) = z/1,  y = 1 Параметрическая: x = 4−t,  y = 1,  z = t
Ответ: (x−4)/(−1)=(y−1)/0=z/1; x=4−t, y=1, z=t
г) Точка пересечения Q прямой L и плоскости Π

Подставляем параметрические уравнения в Π: 2x−y+z=4

2(4−t) − 1 + t = 4 ⇒ 8−2t−1+t = 4 ⇒ 7−t = 4 ⇒ t = 3

x=4−3=1, y=1, z=3.

Ответ: Q(1; 1; 3)

Проверка: в Π: 2·1−1+3=4 ✓; в L: 1−2+3=2 ✓, 1+1+3=5 ✓

Задание 5

Приведение к каноническому виду и построение кривых

При λ=1, μ=2 подставляем коэффициенты в каждое из четырёх уравнений.
а) (μ+1)x²+(λ+6)y²−2(λμ+λ)x+2(λμ+6μ)y+λμ(λ+μ−6)+λ(λ−6)+6μ(μ−6)−36=0

Подставляя λ=1, μ=2: μ+1=3, λ+6=7, λμ+λ=3, λμ+6μ=14, λμ(λ+μ−6)=−6, λ(λ−6)=−5, 6μ(μ−6)=−48.

3x² + 7y² − 6x + 28y − 95 = 0

Выделяем полные квадраты: 3(x²−2x) + 7(y²+4y) = 95

3[(x−1)²−1] + 7[(y+2)²−4] = 95 ⇒ 3(x−1)² + 7(y+2)² = 95+3+28 = 126

(x−1)²/42 + (y+2)²/18 = 1
Ответ: эллипс с центром (1;−2), a=√42≈6,48 (вдоль x), b=√18=3√2≈4,24 (вдоль y)
Эллипс (x−1)²/42+(y+2)²/18=1
б) (λ+1)x²−(μ−1)y²−2(λμ+μ)x+2(λμ+λ)y+λμ(−λ+μ−4)+λ(λ−4)+μ(μ−4)−4=0

λ+1=2, μ−1=1, λμ+μ=4, λμ+λ=3, λμ(−λ+μ−4)=−6, λ(λ−4)=−3, μ(μ−4)=−4.

2x² − y² − 8x + 6y − 17 = 0

2(x²−4x) − (y²−6y) = 17 ⇒ 2[(x−2)²−4] − [(y−3)²−9] = 17

2(x−2)² − 8 − (y−3)² + 9 = 17 ⇒ 2(x−2)² − (y−3)² = 16

(x−2)²/8 − (y−3)²/16 = 1
Ответ: гипербола с центром (2;3), a=√8=2√2≈2,83, b=4, действительная ось вдоль x
Гипербола (x−2)²/8−(y−3)²/16=1 с асимптотами
в) y²+(μ+1)x+2λy+λ²−μ²−3μ−2=0

μ+1=3, 2λ=2, λ²−μ²−3μ−2 = 1−4−6−2=−11.

y² + 3x + 2y − 11 = 0

y²+2y = (y+1)²−1 ⇒ (y+1)² − 1 + 3x − 11 = 0 ⇒ (y+1)² = −3x+12

(y+1)² = −3(x−4)
Ответ: парабола с вершиной (4;−1), ветви влево, параметр 2p=3 (p=3/2)
Парабола (y+1)²=−3(x−4), вершина (4;−1)
г) x²−2μx−(λ+1)y−λ²+μ²−3−4λ=0

2μ=4, λ+1=2, −λ²+μ²−3−4λ = −1+4−3−4=−4.

x² − 4x − 2y − 4 = 0

x²−4x = (x−2)²−4 ⇒ (x−2)² − 4 − 2y − 4 = 0 ⇒ (x−2)² = 2y+8

(x−2)² = 2(y+4)
Ответ: парабола с вершиной (2;−4), ветви вверх, параметр 2p=2 (p=1)
Парабола (x−2)²=2(y+4), вершина (2;−4)
