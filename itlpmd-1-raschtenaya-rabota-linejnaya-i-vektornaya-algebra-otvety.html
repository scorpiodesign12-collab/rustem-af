Задание 1

Вычислить определитель 3-го порядка двумя способами

При n=3, m=3, l=3: (-1)ⁿm=-3, m-4l=-9, m-2l=-3, m-3l=-6, (-1)ⁿ·2=-2, m-10=-7
Δ = | -3 -9 2 ; -3 -6 5 ; -2 -3 -7 |

Способ 1 — разложение по первой строке.

Δ = -3·[(-6)(-7)-5(-3)] - (-9)·[(-3)(-7)-5(-2)] + 2·[(-3)(-3)-(-6)(-2)] Δ = -3·(42+15) + 9·(21+10) + 2·(9-12) = -3·57 + 9·31 + 2·(-3) Δ = -171 + 279 - 6 = 102

Способ 2 — правило треугольников (Саррюса).

Δ = a₁₁a₂₂a₃₃+a₁₂a₂₃a₃₁+a₁₃a₂₁a₃₂ − a₁₃a₂₂a₃₁ − a₁₁a₂₃a₃₂ − a₁₂a₂₁a₃₃ Δ = (-3)(-6)(-7) + (-9)(5)(-2) + (2)(-3)(-3) − (2)(-6)(-2) − (-3)(5)(-3) − (-9)(-3)(-7) Δ = -126 + 90 + 18 − 24 − 45 + 189 = 102
Ответ: Δ = 102 (оба способа дают одинаковый результат)
Задание 2

Решить систему уравнений по формулам Крамера

При n=3, m=3, l=3, (-1)ⁿ=-1, (-1)ⁿ⁺¹=1:
-4x - 6y = -2
6x + 4y = 18

Главный определитель системы:

D = | -4 -6 ; 6 4 | = (-4)(4) - (-6)(6) = -16 + 36 = 20

Определитель для x (столбец коэффициентов при x заменяем свободными членами):

Dₓ = | -2 -6 ; 18 4 | = (-2)(4) - (-6)(18) = -8 + 108 = 100

Определитель для y:

D_y = | -4 -2 ; 6 18 | = (-4)(18) - (-2)(6) = -72 + 12 = -60

По формулам Крамера:

x = Dₓ/D = 100/20 = 5,   y = D_y/D = -60/20 = -3

Проверка: -4·5-6·(-3)=-20+18=-2 ✓;  6·5+4·(-3)=30-12=18 ✓

Ответ: x = 5, y = -3
Задание 3

Решить систему уравнений (а — Крамер, б — метод Гаусса)

При n=3, m=3, l=3:
8x₁ + 5x₂ + x₃ = 6
-3x₁ + 4x₂ + x₃ = -4
-6x₁ - 9x₂ - 2x₃ = -3

а) Метод Крамера. Главный определитель:

D = | 8 5 1 ; -3 4 1 ; -6 -9 -2 | = 8(1)-5(12)+1(51) = 8-60+51 = -1

Заменяя поочерёдно столбцы свободными членами (6, -4, -3):

D₁ = | 6 5 1 ; -4 4 1 ; -3 -9 -2 | = 6(1)-5(11)+1(48) = 6-55+48 = -1 D₂ = | 8 6 1 ; -3 -4 1 ; -6 -3 -2 | = 8(11)-6(12)+1(-15) = 88-72-15 = 1 D₃ = | 8 5 6 ; -3 4 -4 ; -6 -9 -3 | = 8(-48)-5(-15)+6(51) = -384+75+306 = -3 x₁ = D₁/D = -1/-1 = 1,   x₂ = D₂/D = 1/-1 = -1,   x₃ = D₃/D = -3/-1 = 3

б) Метод Гаусса. Прямой ход: исключаем x₁ из 2-го и 3-го уравнений (прибавляем к ним 1-е, умноженное на 3/8 и 3/4 соответственно):

47x₂ + 11x₃ = -14  (из 2-го уравнения, ×8) 21x₂ + 5x₃ = -6  (из 3-го уравнения, ×(-4))

Исключаем x₂: из первого уравнения выражаем x₂=(-6-5x₃)/21 и подставляем во второе (либо умножаем строки на 21 и 47 и вычитаем):

47(-6-5x₃) + 21·11x₃ = -14·21  ⇒   -282-235x₃+231x₃ = -294  ⇒   -4x₃ = -12  ⇒   x₃ = 3

Обратный ход:

21x₂ + 5·3 = -6  ⇒   x₂ = -1 8x₁ + 5·(-1) + 3 = 6  ⇒   x₁ = 1

Результат совпадает с методом Крамера — проверка во все три исходных уравнения выполняется.

Ответ: x₁ = 1, x₂ = -1, x₃ = 3
Задание 4

Скалярное и векторное произведение по модулям и углу

|a|=m+1=4, |b|=l+1=4. c=(m-5)a+(-1)ⁿb=-2a-b, d=(l+(-1)ⁿ+2)a+b=4a+b

а) Скалярное произведение c·d, если (a,^b)=π/3, значит a·b=|a||b|cos(π/3)=4·4·½=8:

c·d = (-2a-b)·(4a+b) = -8(a·a) -2(a·b) -4(a·b) - (b·b) = -8|a|² - 6(a·b) - |b|² c·d = -8·16 - 6·8 - 16 = -128 - 48 - 16 = -192
Ответ: c·d = -192

б) Модуль векторного произведения |c×d|, если (a,^b)=π/2, значит a×a=0, b×b=0 и a·b не участвует:

c×d = (-2a-b)×(4a+b) = -2(a×b) - 4(b×a) = -2(a×b) + 4(a×b) = 2(a×b) |c×d| = 2|a×b| = 2|a||b|sin(π/2) = 2·4·4·1 = 32
Ответ: |c×d| = 32
Задание 5

Векторы в координатах

a=(m-4)i+((-1)ⁿ-l)j+3k = (-1,-4,3), b=(-1)ⁿl·i+(-1)ⁿj+(m-3)k = (-3,-1,0)

а) Скалярное и векторное произведение c и d.

c = (-1)ⁿ(l+1)a + (m-l)b = -4a + 0·b = -4a = (4, 16, -12) d = b + (-1)ⁿ(m+1)a = b - 4a = (-3,-1,0) - (-4,-16,12) = (1, 15, -12) c·d = 4·1 + 16·15 + (-12)(-12) = 4 + 240 + 144 = 388 c×d = | i j k ; 4 16 -12 ; 1 15 -12 | = (-192+180, -(-48+12), 60-16) = (-12, 36, 44)
Ответ: c·d = 388,   c×d = (-12, 36, 44)

б) Длина и направляющие косинусы вектора c = (4, 16, -12):

|c| = √(16+256+144) = √416 = 4√26 ≈ 20,40 cos α = 4/(4√26) = 1/√26 ≈ 0,196 cos β = 16/(4√26) = 4/√26 ≈ 0,785 cos γ = -12/(4√26) = -3/√26 ≈ -0,588
Ответ: |c| = 4√26 ≈ 20,40; cos α=1/√26, cos β=4/√26, cos γ=-3/√26

в) Смешанное произведение (c, d, e), где e = 3j+2k = (0, 3, 2):

d×e = | i j k ; 1 15 -12 ; 0 3 2 | = (30+36, -(2-0), 3-0) = (66, -2, 3) (c,d,e) = c·(d×e) = 4·66 + 16·(-2) + (-12)·3 = 264 - 32 - 36 = 196
Ответ: (c, d, e) = 196
Задание 6

Геометрия треугольника ABC и пирамиды ABCD

A((-1)ⁿm,-l,0)=(-3,-3,0), B((-1)ⁿ2,3,m-4)=(-2,3,-1), C(m-2l,1,3)=(-3,1,3), D(0,(-1)ⁿ,2)=(0,-1,2)

Вспомогательные векторы:

AB = B-A = (1, 6, -1),   AC = C-A = (0, 4, 3),   AD = D-A = (3, 2, 2) BA = (-1,-6,1),   BC = C-B = (-1,-2,4)

а) cos ∠ABC — угол при вершине B между BA и BC:

BA·BC = 1+12+4 = 17,   |BA|=√38,   |BC|=√21 cos ∠ABC = 17/√(38·21) = 17/√798 ≈ 0,602
Ответ: cos ∠ABC = 17/√798 ≈ 0,602

б) Пр_AC AB (проекция AB на направление AC):

AB·AC = 1·0+6·4+(-1)·3 = 21,   |AC| = √(16+9) = 5 Пр_AC AB = (AB·AC)/|AC| = 21/5 = 4,2
Ответ: Пр_AC AB = 4,2

в) S△ABC — площадь треугольника через векторное произведение:

AB×AC = | i j k ; 1 6 -1 ; 0 4 3 | = (18+4, -(3-0), 4-0) = (22, -3, 4) |AB×AC| = √(484+9+16) = √509 ≈ 22,56 S△ABC = ½|AB×AC| = √509/2 ≈ 11,28
Ответ: S△ABC = √509/2 ≈ 11,28

г) Объём пирамиды ABCD через смешанное произведение:

(AB×AC)·AD = 22·3 + (-3)·2 + 4·2 = 66 - 6 + 8 = 68 V = ⅙|(AB×AC)·AD| = 68/6 = 34/3 ≈ 11,33
Ответ: V = 34/3 ≈ 11,33
