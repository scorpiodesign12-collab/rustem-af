Часть 1 · Линейная алгебра

Матрицы и определители

План:
  1. Действия над матрицами
  2. Определители

I. Действия над матрицами

Основное
  • A±B — поэлементно, размеры должны совпадать. λA — умножить каждый элемент.
  • AB: (m×n)·(n×k) = m×k, cᵢⱼ = Σ aᵢₖ·bₖⱼ (строка на столбец). Обычно AB ≠ BA.
  • Aᵀ — строки и столбцы меняются местами.

II. Определители

Основное
  • 2×2: ad − bc. 3×3: правило треугольников (Саррюса).
  • Разложение по строке: Σ aᵢⱼ·(−1)ⁱ⁺ʲ·Mᵢⱼ.
  • Две равные строки → 0; перестановка строк меняет знак; det(AB) = detA·detB.
Часть 1 · Линейная алгебра

Обратная матрица, ранг, матричные уравнения

План:
  1. Обратные матрицы и ранг
  2. Матричные уравнения

III. Обратные матрицы и ранг

Основное
  • A⁻¹ = (1/detA)·(Aᵢⱼ)ᵀ, где Aᵢⱼ — алгебраические дополнения. Существует, если detA ≠ 0.
  • 2×2: A⁻¹ = 1/(ad−bc)·[d −b; −c a]. Проверка: A·A⁻¹ = E.
  • Ранг — наибольший порядок ненулевого минора. Находят приведением к ступенчатому виду.

IV. Матричные уравнения

Основное
  • AX = B → X = A⁻¹B. XA = B → X = BA⁻¹. AXB = C → X = A⁻¹CB⁻¹.
  • Порядок множителей менять нельзя: обратную пишут с той стороны, где стоит A.

V. Системы линейных уравнений

Часть 2 · Векторная алгебра

Векторная алгебра

План:
  1. Координаты, длина, скалярное произведение
  2. Векторное и смешанное произведения

Координаты, длина, скалярное произведение

Основное
  • AB = (x₂−x₁; y₂−y₁; z₂−z₁). |a| = √(x²+y²+z²).
  • a·b = x₁x₂+y₁y₂+z₁z₂ = |a||b|cosφ. Перпендикулярны ⇔ a·b = 0.
  • Проекция: пр_b a = (a·b)/|b|. Коллинеарны ⇔ координаты пропорциональны.

Векторное и смешанное произведения

Основное
  • a×b = определитель с строками (i j k; x₁ y₁ z₁; x₂ y₂ z₂), |a×b| = |a||b|sinφ.
  • Площадь параллелограмма = |a×b|, треугольника = ½|a×b|.
  • (a,b,c) = det 3×3. Объём параллелепипеда = |(a,b,c)|, пирамиды = 1/6 |(a,b,c)|. Компланарны ⇔ (a,b,c) = 0.
Часть 3 · Аналитическая геометрия

Прямая на плоскости и кривые 2-го порядка

План:
  1. Прямая на плоскости
  2. Кривые второго порядка

Прямая на плоскости

Основное
  • y = kx+b; y−y₀ = k(x−x₀); общее Ax+By+C = 0, нормаль n = (A;B).
  • Через две точки: (x−x₁)/(x₂−x₁) = (y−y₁)/(y₂−y₁).
  • Параллельны: k₁ = k₂; перпендикулярны: k₁k₂ = −1. Угол: tgφ = |(k₂−k₁)/(1+k₁k₂)|.
  • Расстояние от точки до прямой: d = |Ax₀+By₀+C|/√(A²+B²).

Кривые второго порядка

Основное
  • Окружность: (x−a)²+(y−b)² = R².
  • Эллипс: x²/a²+y²/b² = 1, c² = a²−b², e = c/a < 1.
  • Гипербола: x²/a²−y²/b² = 1, c² = a²+b², асимптоты y = ±(b/a)x.
  • Парабола: y² = 2px, фокус (p/2; 0), директриса x = −p/2.
Часть 3 · Аналитическая геометрия

Плоскость и прямая в пространстве

План:
  1. Плоскость и прямая в пространстве

Плоскость и прямая в пространстве

Основное
  • Плоскость: Ax+By+Cz+D = 0, n = (A;B;C). Расстояние от точки: |Ax₀+By₀+Cz₀+D|/√(A²+B²+C²).
  • Плоскости параллельны, если n коллинеарны; перпендикулярны, если n₁·n₂ = 0.
  • Прямая: (x−x₀)/m = (y−y₀)/n = (z−z₀)/p, s = (m;n;p). Угол с плоскостью: sinφ = |s·n|/(|s||n|).
Часть 4 · Пределы и производные

Пределы и непрерывность

План:
  1. Пределы и замечательные пределы
  2. Непрерывность, разрывы, асимптоты

Пределы и замечательные пределы

Основное
  • sin x/x → 1; (1+1/x)ˣ → e; (eˣ−1)/x → 1; ln(1+x)/x → 1; (1−cos x)/x² → ½.
  • 0/0 — сократить или Лопиталь; ∞/∞ — делить на старшую степень; ∞−∞ — домножить на сопряжённое; 1^∞ — через e.
  • При x→0: sin x ~ tg x ~ arcsin x ~ x.

Непрерывность, разрывы, асимптоты

Основное
  • Непрерывна в x₀, если lim слева = lim справа = f(x₀).
  • Разрыв I рода: односторонние пределы конечны (равны — устранимый, не равны — скачок). II рода: хотя бы один бесконечен или не существует.
  • Асимптоты: вертикальная x = a; наклонная y = kx+b, k = lim f/x, b = lim (f−kx).
Часть 4 · Пределы и производные

Производная и исследование функции

План:
  1. Производная и правила дифференцирования
  2. Исследование функции

Производная и правила дифференцирования

Основное
  • (xⁿ)′ = nxⁿ⁻¹; (sin x)′ = cos x; (cos x)′ = −sin x; (tg x)′ = 1/cos²x; (eˣ)′ = eˣ; (aˣ)′ = aˣ·ln a; (ln x)′ = 1/x; (arctg x)′ = 1/(1+x²); (arcsin x)′ = 1/√(1−x²).
  • (uv)′ = u′v+uv′; (u/v)′ = (u′v−uv′)/v²; сложная: f(g)′ = f′(g)·g′. Параметрическая: y′ₓ = y′ₜ/x′ₜ.
  • Касательная: y−y₀ = f′(x₀)(x−x₀). Дифференциал: dy = f′dx.

Исследование функции

Основное
  • f′ = 0 — критические точки; f′ > 0 — возрастает. Смена знака f′ с + на − даёт максимум, с − на + даёт минимум.
  • f″ > 0 — выпукла вниз; f″ = 0 с сменой знака — перегиб.
  • Наибольшее и наименьшее на [a;b]: сравнить значения в критических точках и на концах.
  • Лопиталь: lim f/g = lim f′/g′.

Неопределённый интеграл

План:
  1. Первообразная и таблица интегралов
  2. Непосредственное интегрирование
  3. Замена переменной
  4. Интегрирование по частям
  5. Рациональные дроби и тригонометрия

§1. Первообразная и таблица интегралов

Основное
  • F′ = f ⇒ ∫f dx = F+C. (∫f dx)′ = f; ∫f′dx = f+C.
  • ∫xⁿdx = xⁿ⁺¹/(n+1)+C (n ≠ −1); ∫dx/x = ln|x|; ∫eˣ = eˣ; ∫aˣ = aˣ/ln a; ∫sin x = −cos x; ∫cos x = sin x.
  • ∫dx/cos²x = tg x; ∫dx/sin²x = −ctg x; ∫dx/(1+x²) = arctg x; ∫dx/√(1−x²) = arcsin x; ∫dx/(x²−a²) = (1/2a)·ln|(x−a)/(x+a)|.

§2. Непосредственное интегрирование

Основное
  • Линейность: ∫(af+bg) = a∫f+b∫g. Дробь делят почленно, скобки раскрывают.
  • ∫f(ax+b)dx = (1/a)·F(ax+b)+C.

§3. Замена переменной

Основное
  • ∫f(φ(x))φ′(x)dx = ∫f(t)dt, t = φ(x). Это «подведение под знак дифференциала».
  • В конце вернуться к x.

§4. Интегрирование по частям

Основное
  • ∫u dv = uv − ∫v du.
  • За u берут: логарифм, обратные тригонометрические, многочлен. За dv: eˣ, sin x, cos x.

§5. Рациональные дроби и тригонометрия

Основное
  • Неправильную дробь делят с остатком. Правильную раскладывают: A/(x−a) + (Bx+C)/(x²+px+q).
  • sin²x = (1−cos2x)/2; cos²x = (1+cos2x)/2. Универсальная замена t = tg(x/2). При нечётной степени sin или cos заменяют другую функцию.

Определённый и несобственные интегралы

План:

§6–7. Определённый интеграл: свойства и вычисление

Основное
  • Ньютон–Лейбниц: ∫ₐᵇ f dx = F(b)−F(a).
  • ∫ₐᵇ = −∫ᵇₐ; ∫ₐᵇ = ∫ₐᶜ+∫ᶜᵇ. Чётная на [−a;a]: 2∫₀ᵃ; нечётная: 0.
  • При замене меняют пределы. Среднее значение: f_ср = 1/(b−a)·∫ₐᵇ f dx.

§8. Приложения определённого интеграла

Основное
  • Площадь: S = ∫ₐᵇ (f₂−f₁)dx. Объём вращения вокруг Ox: V = π∫ f²dx.
  • Длина дуги: L = ∫√(1+y′²)dx. Путь: s = ∫v dt. Работа: A = ∫F dx.

§9. Несобственные интегралы

Основное
  • ∫ₐ^∞ f dx = lim ∫ₐᵇ f dx при b→∞. Сходится, если предел конечен.
  • ∫₁^∞ dx/xᵖ сходится при p > 1; ∫₀¹ dx/xᵖ сходится при p < 1.

Дифференциальные уравнения

План:
  1. ДУ: основные понятия, разделяющиеся переменные

  3. ДУ высших порядков и приложения

§10–11. ДУ: основные понятия, разделяющиеся переменные

Основное
  • Порядок — старшая производная. Общее решение содержит констант столько, каков порядок. Частное находят из начальных условий (задача Коши).
  • y′ = f(x)g(y) ⇒ dy/g(y) = f(x)dx, затем интегрировать. Не потерять решения g(y) = 0.
  • Однородное y′ = f(y/x): замена z = y/x.

§12. Линейные ДУ первого порядка

Основное
  • y′+p(x)y = q(x): подстановка y = u·v. Сначала v из v′+pv = 0, затем u из u′v = q.
  • Бернулли: y′+py = qyⁿ — та же подстановка.

§13–14. ДУ высших порядков и приложения

Основное
  • y″ = f(x) — интегрировать дважды. Линейное y″+py′+qy = 0: характеристическое уравнение k²+pk+q = 0.
  • k₁ ≠ k₂: y = C₁e^(k₁x)+C₂e^(k₂x). k₁ = k₂: y = (C₁+C₂x)e^(kx). k = α±βi: y = e^(αx)(C₁cosβx+C₂sinβx).
  • Неоднородное: y = y_одн + y_частное. Рост и распад: dN/dt = kN ⇒ N = N₀e^(kt).

§15–17. Комплексные числа

Основное
  • z = a+bi, i² = −1; z̄ = a−bi; z·z̄ = |z|² = a²+b². Деление: умножить числитель и знаменатель на сопряжённое.
  • z = r(cosφ+i sinφ) = re^(iφ). Умножение: модули перемножают, аргументы складывают. Деление: модули делят, аргументы вычитают.
  • Муавр: zⁿ = rⁿ(cos nφ+i sin nφ). Корень: ⁿ√z = ⁿ√r·(cos((φ+2πk)/n)+i sin((φ+2πk)/n)), k = 0…n−1.
  • Аналитичность — условия Коши–Римана: uₓ = vᵧ, uᵧ = −vₓ.

§18. Интегралы от ФКП и вычеты

Основное
  • ∮f dz = 2πi·Σ res f. ∮dz/(z−a) = 2πi, если a внутри контура.
  • Простой полюс: res = lim (z−a)f(z). Полюс порядка n: res = 1/(n−1)!·lim dⁿ⁻¹/dzⁿ⁻¹[(z−a)ⁿf(z)].

План:

§19. Частные производные

Основное
  • ∂z/∂x — дифференцируем по x, считая y постоянной. Смешанные: z″ₓᵧ = z″ᵧₓ.
  • Полный дифференциал: dz = zₓdx + zᵧdy.

§20, 26. Градиент и производная по направлению

Основное
  • grad u = (uₓ; uᵧ; u_z). ∂u/∂l = grad u · l/|l|.
  • Быстрее всего функция растёт по направлению grad u, скорость роста равна |grad u|.

§21. Экстремумы, касательная плоскость

Основное
  • zₓ = zᵧ = 0 — стационарные точки. A = zₓₓ, B = zₓᵧ, C = zᵧᵧ, Δ = AC−B².
  • Δ > 0 и A > 0 — минимум; Δ > 0 и A < 0 — максимум; Δ < 0 — экстремума нет.
  • Касательная плоскость: z−z₀ = zₓ(x−x₀)+zᵧ(y−y₀). Для F(x,y,z) = 0 нормаль — grad F.

§22–23. Двойной и тройной интегралы

Основное
  • ∬f dxdy = ∫ₐᵇdx ∫ f dy (повторный интеграл). Площадь: S = ∬dxdy.
  • Полярные: x = r cosφ, y = r sinφ, dxdy = r dr dφ.
  • Цилиндрические: dV = r dr dφ dz. Сферические: dV = ρ²sinθ dρ dθ dφ. Объём: V = ∭dV.

§24. Криволинейные интегралы, формула Грина

Основное
  • I рода ∫f dl не зависит от направления обхода. II рода ∫P dx+Q dy меняет знак при смене направления.
  • Грин: ∮P dx+Q dy = ∬(Q′ₓ−P′ᵧ)dxdy (обход против часовой стрелки).
  • Интеграл не зависит от пути, если Q′ₓ = P′ᵧ.

§25, 27. Поверхностные интегралы, теория поля

Основное

§28–29. Числовые ряды и признаки сходимости

Основное
  • Ряд сходится, если существует конечный lim Sₙ. Необходимый признак: aₙ → 0 (если не так — расходится; обратное неверно).
  • Геометрический Σqⁿ сходится при |q| < 1, сумма a/(1−q). Σ1/n расходится; Σ1/nᵖ сходится при p > 1.
  • Даламбер: D = lim aₙ₊₁/aₙ (<1 сходится, >1 расходится). Коши: lim ⁿ√aₙ. Сравнение, интегральный признак.
  • Лейбниц: знакочередующийся ряд с убывающим по модулю aₙ → 0 сходится. Абсолютная сходимость — сходится ряд из модулей.

§30. Степенные ряды

Основное
  • Σaₙ(x−x₀)ⁿ. Радиус: R = lim |aₙ/aₙ₊₁|. Интервал (x₀−R; x₀+R).
  • Концы интервала проверяют отдельно.

§31. Ряды Маклорена и Фурье

Основное
  • f(x) = Σ f⁽ⁿ⁾(0)xⁿ/n!. eˣ = Σxⁿ/n!; sin x = x−x³/3!+x⁵/5!−…; cos x = 1−x²/2!+x⁴/4!−…
  • 1/(1−x) = Σxⁿ, |x| < 1; ln(1+x) = x−x²/2+x³/3−…
  • Фурье: f = a₀/2+Σ(aₙcos nx+bₙsin nx); aₙ = (1/π)∫₋π^π f cos nx dx, bₙ — с sin nx. Чётная — только косинусы, нечётная — только синусы. В точке разрыва — среднее значение.

Теория вероятностей и статистика

План:
  1. Определение вероятности
  2. Алгебра событий, теоремы сложения и умножения
  3. Случайные величины и законы распределения
  4. Элементы математической статистики

§32. Определение вероятности

Основное
  • Классическая: P(A) = m/n. 0 ≤ P ≤ 1; достоверное — 1, невозможное — 0.
  • Комбинаторика: Pₙ = n!; размещения Aₙᵐ = n!/(n−m)!; сочетания Cₙᵐ = n!/(m!(n−m)!).

§33. Алгебра событий, теоремы сложения и умножения

Основное
  • P(A+B) = P(A)+P(B)−P(AB); для несовместных — просто сумма. P(Ā) = 1−P(A).
  • P(AB) = P(A)·P(B|A); для независимых P(AB) = P(A)P(B).
  • Полная вероятность: P(A) = ΣP(Hᵢ)P(A|Hᵢ). Байес: P(Hᵢ|A) = P(Hᵢ)P(A|Hᵢ)/P(A).
  • Бернулли: Pₙ(k) = Cₙᵏ pᵏ qⁿ⁻ᵏ, q = 1−p.

§34. Случайные величины и законы распределения

Основное
  • Ряд распределения: ΣPᵢ = 1. M(X) = Σxᵢpᵢ; D(X) = M(X²)−M²(X); σ = √D.
  • M(aX+b) = aM+b; D(aX+b) = a²D; M(X+Y) = MX+MY; для независимых D(X+Y) = DX+DY.
  • F(x) = P(X < x); плотность f = F′, ∫f dx = 1.
  • Биномиальное: M = np, D = npq. Пуассон: M = D = λ. Равномерное: M = (a+b)/2, D = (b−a)²/12. Нормальное N(a, σ²): правило трёх сигм.

§35. Элементы математической статистики

Основное
  • Выборочное среднее: x̄ = Σxᵢnᵢ/n. Дисперсия: D = x̄² − (x̄)². Исправленная: s² = n/(n−1)·D.
  • Мода — самое частое значение; медиана — серединное. Графики: полигон и гистограмма частот.
