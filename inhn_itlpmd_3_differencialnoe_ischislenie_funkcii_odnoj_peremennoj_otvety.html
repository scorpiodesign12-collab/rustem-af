Задание 1

Вычислить y′(x)

Вариант n=3: φ(x)=e^(x−1)−1, x₀=1. При k=8, m=4:
y(x) = φ(x)·(x+x₀+1)^k·(x−k)^m / (x−x₀+1)^(m+1) = (e^(x−1)−1)(x+2)⁸(x−8)⁴ / x⁵

Функция — произведение и частное степеней, поэтому удобнее всего логарифмическое дифференцирование: берём модуль, логарифмируем обе части, а затем дифференцируем как сложную функцию.

ln|y| = ln|e^(x−1)−1| + 8·ln|x+2| + 4·ln|x−8| − 5·ln|x|

Дифференцируем обе части по x (слева — производная логарифма функции, т.е. y′/y):

y′/y = e^(x−1)/(e^(x−1)−1) + 8/(x+2) + 4/(x−8) − 5/x

Отсюда y′ = y·[...], то есть:

Ответ: y′(x) = (e^(x−1)−1)(x+2)⁸(x−8)⁴/x⁵ · [ e^(x−1)/(e^(x−1)−1) + 8/(x+2) + 4/(x−8) − 5/x ]
Задание 2

Вычислить производную функции

Вариант n=3: φ(x)=arctg(x+1), ψ(x)=sin√x. k=8, m=4 (из задания 1).
y = φ[ψ(x)] / (ᵐ√(x^k)+1)^((−1)ⁿ) + φ(x)^ψ(x)

Сначала упростим знаменатель первого слагаемого: ᵐ√(x^k) = x^(k/m) = x^(8/4) = x². Показатель степени (−1)ⁿ = (−1)³ = −1, поэтому (x²+1)^(−1), а деление на него — это умножение на (x²+1):

y = arctg(sin√x + 1)·(x²+1) + (arctg(x+1))^(sin√x)

Первое слагаемое u(x) = arctg(sin√x+1)·(x²+1) — произведение, дифференцируем по правилу произведения; внутренняя производная по цепному правилу:

[arctg(sin√x+1)]′ = cos√x /(2√x) · 1/(1+(sin√x+1)²) u′(x) = (x²+1)· cos√x /[2√x(1+(sin√x+1)²)] + 2x·arctg(sin√x+1)

Второе слагаемое v(x) = (arctg(x+1))^(sin√x) — степенно-показательная функция, логарифмируем:

ln v = sin√x · ln(arctg(x+1)) v′/v = cos√x/(2√x) · ln(arctg(x+1)) + sin√x · 1/[(1+(x+1)²)·arctg(x+1)] v′(x) = (arctg(x+1))^(sin√x) · { cos√x/(2√x)·ln(arctg(x+1)) + sin√x /[(1+(x+1)²)·arctg(x+1)] }
Ответ: y′(x) = u′(x) + v′(x), где u′, v′ приведены выше (y′ = сумма этих двух выражений)
Задание 3

Уравнение нормали к y=f(x) в точке x₀

Вариант n=3: f(x) = x − x³, x₀ = −1

f(−1) = −1 − (−1)³ = −1+1 = 0 — точка касания (−1; 0).

f′(x) = 1 − 3x² ⇒ f′(−1) = 1 − 3 = −2.

Уравнение нормали: y − f(x₀) = −1/f′(x₀) · (x − x₀)

y − 0 = −1/(−2) · (x+1) = 1/2·(x+1)
Ответ: y = (x+1)/2, или x − 2y + 1 = 0
Задание 4

Приближённое вычисление с помощью дифференциала

Вариант n=3: y(x) = (x+√(5−x²))/2, x₀ = 0,98

Берём «удобную» базовую точку a=1, близкую к x₀=0,98, Δx = x₀ − a = −0,02.

y(a) = y(1) = (1+√(5−1))/2 = (1+2)/2 = 1,5

Находим производную:

y′(x) = [1 − x/√(5−x²)] / 2 y′(1) = [1 − 1/2]/2 = 1/4 = 0,25

Дифференциал: dy = y′(a)·Δx = 0,25·(−0,02) = −0,005

y(0,98) ≈ y(1) + dy = 1,5 − 0,005 = 1,495
Ответ: y(0,98) ≈ 1,495
Задание 5

Касательная к параметрически заданной кривой

Вариант n=3: x(t) = a(t−sin t), y(t) = a(1−cos t), t₀ = π/3

Точка касания:

x₀ = a(π/3 − sin(π/3)) = a(π/3 − √3/2) y₀ = a(1 − cos(π/3)) = a(1 − 1/2) = a/2

Производные по параметру: x′(t) = a(1−cos t), y′(t) = a·sin t. При t₀=π/3:

x′(π/3) = a(1−1/2) = a/2,   y′(π/3) = a·√3/2

Угловой коэффициент касательной:

k = y′(t₀)/x′(t₀) = (a√3/2)/(a/2) = √3

Уравнение касательной: y − y₀ = √3·(x − x₀)

y − a/2 = √3·[x − a(π/3 − √3/2)]
Ответ: y = √3·x + a(2 − π√3/3)

Задание 8

Исследование функции и построение графика

Вариант n=3: f(x) = √(x+1)/√x = √((x+1)/x)

1. Область определения. Нужно x+1≥0 и x>0 (знаменатель), значит D(f) = (0; +∞).

2. Асимптоты. При x→0⁺: f(x)→+∞ — вертикальная асимптота x=0. При x→+∞: f(x)=√(1+1/x)→1 — горизонтальная асимптота y=1. Наклонных асимптот нет (есть горизонтальная).

3. Производная. Перепишем f(x)=(x+1)^(1/2)·x^(−1/2) и применим правило произведения:

f′(x) = ½(x+1)^(−1/2)x^(−1/2) − ½(x+1)^(1/2)x^(−3/2) = ½x^(−3/2)(x+1)^(−1/2)[x−(x+1)] f′(x) = −1 / [2√(x³(x+1))]

f′(x) < 0 при всех x∈(0;+∞) ⇒ функция строго убывает на всей области определения, критических точек (экстремумов) нет.

4. Вторая производная.

f″(x) = ¾x^(−5/2)(x+1)^(−1/2) + ¼x^(−3/2)(x+1)^(−3/2)

Оба слагаемых положительны при x>0 ⇒ f″(x)>0 всюду ⇒ график вогнут вверх (выпуклый вниз) на всей области определения; точек перегиба нет.

5. Контрольная точка: f(1) = √2 ≈ 1,414.

Вывод: функция определена на (0;+∞), непрерывно убывает от +∞ до 1, всюду выпукла вниз; асимптоты x=0 и y=1, экстремумов и перегибов нет.
График f(x)=√((x+1)/x): убывает от +∞ к 1, выпуклый вниз
Задание 9

Задача на экстремум

Вариант n=3: «Из деревянного шара требуется вырезать цилиндр наибольшего объёма»

Пусть R — радиус шара (дан), r — радиус цилиндра, h — его высота. Из сечения шара плоскостью, проходящей через ось цилиндра, видно прямоугольный треугольник со связью:

r² + (h/2)² = R²  ⇒   r² = R² − h²/4

Объём цилиндра:

V(h) = πr²h = π(R² − h²/4)h = πR²h − (π/4)h³

Находим критическую точку:

V′(h) = πR² − (3π/4)h² = 0  ⇒   h² = 4R²/3  ⇒   h = 2R/√3 = 2R√3/3

V″(h) = −(3π/2)h < 0 при h>0 ⇒ это максимум.

Находим соответствующий радиус:

r² = R² − (1/4)(4R²/3) = R² − R²/3 = 2R²/3  ⇒   r = R√(2/3) = R√6/3

Максимальный объём:

V_max = πr²h = π·(2R²/3)·(2R/√3) = 4πR³/(3√3) = 4√3πR³/9
Ответ: h = 2R√3/3, r = R√6/3, V_max = 4√3πR³/9 ≈ 0,77·πR³
